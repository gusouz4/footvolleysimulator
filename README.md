# Footvolley Simulator

Futevôlei 3D arcade, offline e online.

## Como instalar (Windows)

1. Abra a página [Releases](https://github.com/gusouz4/footvolleysimulator/releases/latest).
2. Baixe o arquivo `Footvolley-Simulator-Instalador-*.exe` e abra.
3. Se aparecer "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.

O jogo cria um atalho na área de trabalho e se atualiza sozinho ao abrir.
